The two risk methods and Decision Matrix retain their existing dedicated editors. Other structured methods use schema-driven forms and preserve saved dictionary shapes. F6 on structured/guided screens opens advanced JSON; forms support Markdown/JSON exports, while deep or dynamic map-based methods still need more tailored controls. AI text suggestions on schema forms appear only after requesting them, and numbers are never imported from AI. This screenshot set is a UI walk-through, not a validated study or user evidence.
