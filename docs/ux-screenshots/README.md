The two risk methods and Decision Matrix retain their existing dedicated editors. Other structured methods use schema-driven forms and preserve saved dictionary shapes. F6 on structured/guided screens opens advanced JSON; forms support Markdown/JSON exports. Value of Information and Strategy Stress Test have label-keyed judgment grids. Monte Carlo variables expose distribution-specific inputs, including repeatable discrete values/weights and empirical samples; switching distributions retains saved judgments. Other deeply nested methods may still need tailored controls. Per-field AI text drafts on schema, guided and dedicated screens are opt-in, editable and require Accept; numeric judgments are never imported from AI. In a scored Decision Matrix, revising option or criterion labels opens a mapping dialog: confirm which existing row each label represents; new rows have blank judgments. Any unmapped scored row requires a separate discard confirmation. Editing unscored handoff labels needs no mapping. This screenshot set is a UI walk-through, not a validated study or user evidence.
