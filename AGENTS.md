# ThinkTUI contributor / agent guide

- `src/thinktui/core.py`: session model, registry and method protocol. Older methods live in `methods.py`; staged methods live in `advanced_decisions.py`, `forecasting.py`, and `strategy_risk.py`; remaining catalog methods live in `catalog_decisions.py`, `catalog_risk_forecast.py` and `catalog_systems.py`. Rule-based recommendations, cross-analysis draft transfers and disclosure rules live in `planning.py`. Each new method needs deterministic validation, calculation, example/schema, registration, math tests, TUI save/resume/export tests, and a documented interpretation. The generic JSON worksheet supports staged methods while dedicated workflow widgets are built. Never treat examples as user evidence. AI must never calculate numbers or silently change judgments.
- `src/thinktui/storage.py`: SQLite schema and migration versions; do not change a shipped table without a forward migration. Keep transactions atomic and events append-only. Do not store API keys, tokens, or credentials in settings, exports, events, or logs.
- `src/thinktui/ai.py`: provider isolation; no undocumented authentication, browser-cookie access, or reuse of another program's tokens. New AI suggestions must remain separate until explicitly accepted. Keep context whitelisted; avoid sending notes or project history automatically. Avoid leaking credentials via errors. New providers are a `Preset` in `PRESETS` (OpenAI-compatible services need no new class). Providers implement `stream()` (chunks) and `complete()`; subscription access goes only through the vendor's official CLI (`SubscriptionCLI`), never through its token files. API keys go only through `src/thinktui/credentials.py` (session → OS keyring → env var). Tests use the autouse `isolated_ai` fixture: network and keyring are faked.
- `src/thinktui/issue_tree.py`: parent-linked tree editing, traversal and legacy flat-entry migration. Export complete nested trees even when collapsed. `src/thinktui/screens.py`: UI only; calculations and persistence belong to their services. Keyboard paths must work without a mouse. Autosave meaningful changes.
- `src/pairwise_prioritizer/`: legacy PairRank application and tested comparison engine. Preserve its CLI and tests; ThinkTUI currently imports the engine.
- Tests: `tests/test_thinktui.py` covers repository, calculations and Textual pilot. Add fixtures and regression tests for every new method or migration. Never require a live AI endpoint for tests.
- Quality: `uv sync && uv run ruff format . && uv run ruff check . && uv run pytest`. Launch with `uv run thinktui`; `uv run thinktui doctor` checks local configuration.
- Product limitations and future work belong in README; do not claim a built-in ChatGPT OAuth client (ChatGPT sign-in goes through the official Codex CLI), full 40-method catalog, or tree widgets without implementing and testing them.
